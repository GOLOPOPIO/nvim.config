# Vim/Neovim: шпаргалка

## Перемещение по файлу (Normal mode)

| Клавиши | Действие |
| --- | --- |
| h j k l | влево / вниз / вверх / вправо |
| w / W | к началу след. слова / WORD (игнорируя пунктуацию) |
| b / B | к началу пред. слова / WORD |
| e / E | к концу слова / WORD |
| ge / gE | к концу предыдущего слова / WORD |
| 0 | в начало строки |
| ^ | на первый непробельный символ строки |
| $ | в конец строки |
| gg | в начало файла |
| G | в конец файла |
| {n}G или :{n} | на строку n |
| { / } | на абзац назад / вперёд |
| % | к парной скобке `({[( )]})` |
| f{c} / F{c} | к след./пред. символу c в строке |
| t{c} / T{c} | перед след./пред. символом c |
| ; / , | повторить f/t в том же / обратном направлении |
| Ctrl-d / Ctrl-u | прокрутка на пол-экрана вниз/вверх |
| Ctrl-f / Ctrl-b | прокрутка на экран вниз/вверх |
| zz / zt / zb | центрировать / прижать наверх / прижать вниз текущую строку |
| H / M / L | наверх / середину / низ видимого экрана |
| m{a} | поставить метку a |
| \`{a} / '{a} | перейти к метке a (точно / на начало строки) |
| Ctrl-o / Ctrl-i | назад / вперёд по jumplist |

## Визуальный режим

| Клавиши | Действие |
| --- | --- |
| v / V / Ctrl-v | посимвольное / построчное / блочное выделение |
| gv | восстановить последнее выделение |
| o | прыгнуть на другой конец выделения |

## Текстовые объекты (после d/c/y/v)

| Объект | Значение |
| --- | --- |
| iw / aw | слово без пробелов вокруг / со пробелами |
| i" a" / i( a( / i{ a{ / i\[ a\[ | внутри кавычек или скобок / включая их |
| it / at | внутри HTML/XML-тега / включая сам тег |
| ip / ap | абзац без / с пустой строкой после |

Примеры: `ciw` — заменить слово под курсором, `di(` — очистить содержимое скобок, `ya"` — скопировать строку в кавычках вместе с кавычками.

## Регистры и макросы

| Клавиши | Действие |
| --- | --- |
| "{a}yy | скопировать строку в регистр a |

## Буферы

| Команда | Действие |
| --- | --- |
| :e {file} | открыть файл в новом буфере |
| :ls или :buffers | список открытых буферов |
| :b {N} / :b {имя} | перейти к буферу по номеру / по имени (можно часть имени) |
| :bn / :bp | следующий / предыдущий буфер |
| :bd | закрыть (удалить) текущий буфер |
| :bd {N} | закрыть конкретный буфер по номеру |
| Ctrl-^ (Ctrl-6) | переключиться на предыдущий буфер |

У тебя уже есть свой шорткат под это: `b<Tab>` → `:ls<CR>:b<Space>`.

## Табы (вкладки)

| Команда | Действие |
| --- | --- |
| :tabnew {file} | открыть файл в новой вкладке |
| gt / gT | следующая / предыдущая вкладка |
| {N}gt | перейти на вкладку номер N |
| :tabclose | закрыть текущую вкладку |
| :tabonly | закрыть все вкладки кроме текущей |
| :tabs | список вкладок и их буферов |
| :tabmove {N} | переместить вкладку на позицию N |

Важный момент: вкладка в Vim — это не «файл», а отдельный набор окон/раскладка. Между открытыми файлами обычно переключаются через буферы, а табы используют для разных layout'ов (например, разные проекты или контексты).

## :Ex (netrw) — встроенный файловый менеджер

`:Ex` (или `:Explore`) открывает netrw в директории текущего файла. У тебя выставлен `netrw_liststyle = 3` — древовидный вид.

| Клавиша | Действие |
| --- | --- |
| Enter | открыть файл / зайти в папку |
| - | подняться на директорию выше |
| i | переключить стиль отображения (thin/long/wide/tree) |
| gh | показать/скрыть скрытые файлы |
| s | сменить критерий сортировки (имя/время/размер) |
| r | развернуть сортировку в обратном порядке |
| % | создать новый файл |
| d | создать новую директорию |
| D | удалить файл/директорию под курсором |
| R | переименовать файл/директорию под курсором |
| mf | пометить файл (можно несколько подряд) |
| mt | назначить текущую директорию как цель для операций |
| mc | скопировать помеченные файлы в целевую директорию |
| mm | переместить помеченные файлы в целевую директорию |
| mu | снять все пометки |
| o | открыть в горизонтальном сплите |
| v | открыть в вертикальном сплите |
| t | открыть в новой вкладке |
| p | предпросмотр файла в отдельном окне |
| qf | показать информацию о файле |
| x | открыть файл ассоциированной системной программой |

## Твои настроенные хоткеи

| Клавиши | Действие |
| --- | --- |
| `b<Tab>` | список буферов + переход (`:ls` / `:b`) |
| `<M-r>n` | переименовать символ (`vim.lsp.buf.rename`) |
| `<M-e>` | диагностика под курсором (`vim.diagnostic.open_float`) |
| `<M-f>` | форматировать буфер (C# — csharpier, остальное — LSP) |
| `<M-n>` | меню шаблонов файлов (`:Template`) |
| `<M-b>` | `dotnet build` → quickfix |
| `<M-t>` | `dotnet test` → quickfix |
| `<M-r>r` | `dotnet run` в терминале |

`:<M-...>` — это Alt (Option) + клавиша; в терминале может понадобиться `Option as Meta`.

## .NET: подсветка, шаблоны файлов и команды

### Новые типы файлов

| Файл | filetype | Что работает |
| --- | --- | --- |
| `*.cshtml`, `*.razor` | razor | HTML + C# в `@{ }`, `@code { }`, `@(...)`, `@Model.X`, `@if`, директивы `@page`/`@model`/`@inject` |
| `*.xaml`, `*.axaml` | xaml | XML + `{Binding}`, `{StaticResource}`, `x:Class` |
| `*.csproj`, `*.props`, `*.targets`, `*.slnx` | xml | обычный XML |
| `*.psql`, `*.pgsql`, `*.plpgsql`, `*.sql` | sql | PostgreSQL: `RETURNING`, `ON CONFLICT`, `::`, `jsonb_*`, `\dt` и psql-метакоманды |
| `*.cs` | cs | C# 11+: `required`, `file`, `scoped`, `with { }` |

`%` работает по парным HTML/XML-тегам (встроенный matchit, без плагинов).

### Шаблоны файлов — `:Template` (или `<M-n>`)

`:Template` — меню, `:Template <шаблон> [имя] [папка]` — сразу. Файл создаётся рядом с текущим файлом (в netrw — в открытой папке), namespace берётся из ближайшего `.csproj`.

| Шаблон | Что создаёт |
| --- | --- |
| `class`, `interface`, `record`, `struct`, `enum` | обычный C#-файл |
| `controller Products` | `ProductsController.cs` (API-контроллер) |
| `razor-page Index Pages` | `Pages/Index.cshtml` + `Index.cshtml.cs` |
| `razor-view` | MVC-представление `.cshtml` |
| `blazor` | Blazor-компонент `.razor` |
| `maui-page MainPage Views` | `MainPage.xaml` + `MainPage.xaml.cs` |
| `viewmodel`, `dbcontext`, `entity`, `middleware`, `options`, `test`, `program` | типовые классы .NET |
| `sql`, `html`, `json`, `xml` | заготовки файлов |

Примеры: `:Template class Product`, `:Template test Orders` → `OrdersTests.cs`, `:Template controller Products`.

### Форматирование C# — csharpier

Установлен `csharpier` 1.4.0 (`dotnet tool install -g csharpier`), работает как CLI, плагин не нужен.

- при сохранении `*.cs` файл автоматически форматируется csharpier;
- `<M-f>` — отформатировать буфер вручную;
- `:Csharpier` — форматирует буфер (сохранить — `:w`), при синтаксических ошибках покажет их (при сохранении такие ошибки просто пропускаются, файл пишется как есть);
- настройки берутся из `.editorconfig`, `.csharpierrc.json`, `.csharpierignore` в проекте.

Lua форматируется `stylua` при сохранении (тем же способом, через `vim.system`). Остальные типы файлов (python, json, sql, ...) форматируются через LSP, если у сервера есть formatting.

### Команды dotnet

| Команда | Действие |
| --- | --- |
| `:Dotnet build` | сборка проекта, ошибки в quickfix (`:copen`) |
| `:Dotnet test` | тесты, ошибки в quickfix |
| `:Dotnet run`, `:Dotnet watch` | запуск в терминале (сплит снизу) |
| `:Dotnet restore`, `:Dotnet format`, `:Dotnet publish`, `:Dotnet pack` | как обычно |
| `:DotnetNew` | интерактивно `dotnet new` (список шаблонов SDK) |
| `:make` | то же, что `:Dotnet build` |

Корень проекта ищется вверх по дереву: `.sln`, `.slnx`, `.csproj`, `global.json`.

| Клавиши | Действие |
| --- | --- |
| `<M-n>` | меню шаблонов |
| `<M-b>` | `dotnet build` |
| `<M-t>` | `dotnet test` |
| `<M-r>r` | `dotnet run` |
| `<M-r>n` | переименовать символ |
| `<M-e>` | диагностика под курсором |
| `<M-f>` | форматировать буфер |
